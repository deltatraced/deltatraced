2026-11-01 Wk 44 Sun - 05:19 +03:00

https://www.jonmsterling.com/019E/  Pterodactyl proof assistant project by Jon Sterling. One thing they mention in univalent agda discord server is that it differs from Agda in that there is no termination oracle, rather users of the language can directly provide a termination argument. They also state that this is good for correctness in that, the only recursive definitions that pass are those with implemented rules, rather than passing everything and blocking some. They also mention this is useful pedagogically since in learning math it is important that we explain how a definition terminations, not just that it does.
