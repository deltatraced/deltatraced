This is a note handle: [007 Handles on note names can be used for modular extensions](007%20Handles%20on%20note%20names%20can%20be%20used%20for%20modular%20extensions.md)

`Iterations for N` for some note `N` routes to multiple `Iteration M N` subnotes that branch off of `N` in some way. These can include any subpath of `N`, and can be used to write `N` by iterative search (contra [011 Redos for Note Handle routes multiple full redoing of a given note](011%20Redos%20for%20Note%20Handle%20routes%20multiple%20full%20redoing%20of%20a%20given%20note.md)).
