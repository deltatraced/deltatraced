This is a note handle: [[007 Handles on note names can be used for modular extensions]]

`Iterations for N` for some note `N` routes to multiple `Iteration M N` subnotes that branch off of `N` in some way. These can include any subpath of `N`, and can be used to write `N` by iterative search (contra [[011 Redos for Note Handle routes multiple full redoing of a given note]]).
