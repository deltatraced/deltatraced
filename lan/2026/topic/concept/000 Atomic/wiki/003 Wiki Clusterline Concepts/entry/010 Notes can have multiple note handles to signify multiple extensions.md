We explored that [007 Handles on note names can be used for modular extensions](007%20Handles%20on%20note%20names%20can%20be%20used%20for%20modular%20extensions.md). Some handles are compatible with others, giving a compositional expression that a note satisfies multiple expectations.

For example,  the [009 Proc Note handle differentiates notes in wikiproc instead of wiki](009%20Proc%20Note%20handle%20differentiates%20notes%20in%20wikiproc%20instead%20of%20wiki.md), and it can be paired with other handles, as differentiation of wiki/wikiproc can be done also for Erratas: [008 Errata note extensions capture author made errors without cluttering the note](008%20Errata%20note%20extensions%20capture%20author%20made%20errors%20without%20cluttering%20the%20note.md)
