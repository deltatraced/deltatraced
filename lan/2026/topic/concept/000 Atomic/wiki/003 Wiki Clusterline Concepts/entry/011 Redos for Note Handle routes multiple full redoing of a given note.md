This is a note handle: [007 Handles on note names can be used for modular extensions](007%20Handles%20on%20note%20names%20can%20be%20used%20for%20modular%20extensions.md).

`Redos for N` for some note `N` allows us to route to different `Redo M N` notes, where `M` is the `mth` redo. This lets us for example solve problems in different ways, and explain different approaches taken to arrive at the same endpoint.
