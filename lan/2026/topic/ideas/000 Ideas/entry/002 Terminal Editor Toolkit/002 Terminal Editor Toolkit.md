# Idea

It would be cool to just build the text editor you use via fundamental interacting components. Sort of like how we can build a gentoo system by interacting packages that respond to each others' presence with use flags. gentoo is described as a meta linux distribution. This would be a meta terminal editor!

Then we wouldn't need a plugin system - there is nothing to plug anywhere. You just put a new block and create a brand new text editor. As long as the components are sourced appropriately, anyone can share the `main.rs` where the editor is created via attaching blocks. It can also specify many feature flags that change how many components simultaneously interoperate to implement a new feature, so that customization is done both at the feature set and component set.
