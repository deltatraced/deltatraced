# 1 Day Overview

The big focus here was to learn about build and deployment details on various web technologies.

We managed to deploy a static and a php website to [wasmer.io](https://wasmer.io/).

We fixed some practices and added a few extra details on deployment and pre-commit hooks for automatic style/linting/tests to be able to run on commit. The comment can be found here: [gh wwebdev-comments #3](https://github.com/Vincenius/wwebdev-comments/issues/3)

We investigated the possibility of launching web projects across different tech stacks on wasmer under the same domain (for example, www.domain.com/service1, www.domain.com/service2). We reached out to the core team to clarify on this feature. They found the use case interesting, but it is not currently possible, so routing will have to be done at the application layer.

We successfully deployed our obsidian vault notes using [Perlite](https://github.com/secure-77/Perlite), it has the basic text rendering but currently lacks images, graphs, some note-local links are not rendering, and some deprecation warnings show on some pages. More issues to investigate!
