# 1 Objective

We have proposed a concept of Extension Tables here: [Configurable Extension Tables with extension compatibility rules](https://github.com/dbmint/dbmint-notes/blob/a9e8bd75959c08643bc8f20108c8bfe027058945/lan/docs/2025/001%20New%20Feature%20Proposals.md#73-configurable-extension-tables-with-extension-compatibility-rules)

We need to explore this concept and build a demo around it with the example domain of a Robo Kit.

We will implement a proof of concept for extension tables as well as a demo application for it.
